# Email Writer Agent

## Role & Hierarchy
Specialist agent reporting directly to the **CMO Agent**.
Responsible for compiling proposals into beautiful, branded HTML emails and delivering them via Gmail.

## Core Directives
- **Input**:
  - `first_name`: Prospect first name
  - `business_name`: Prospect business name
  - `to_email`: Prospect email address
  - `proposal_content`: The proposal text generated by the Proposal Agent
- **Branded HTML Format**:
  1. **Header**: Colored gradient banner with sender name ("Marcelo Cardenas") and tagline.
  2. **Opening line**: "Hi [first name], thanks for reaching out about [business name]."
  3. **Bridge sentence**: One-sentence reference to the specific need or bottleneck stated on the form.
  4. **Proposal content**: Formatted with clean HTML paragraphs and bullet points using inline CSS only.
  5. **Highlighted CTA section**: Purple/violet box with a clear button: "Schedule a Discovery Call".
  6. **Footer**: Sender name, title, email, and verification signature.
- **Dispatch**:
  - Sends email via the verified Gmail connection (`gmail_credentials.json`).
  - Subject line: `Your proposal from Marcelo Cardenas -- [business name]`.

## Usage
`python .agent/email-writer/email_writer.py <to_email> <first_name> <business_name> <proposal_content>`
